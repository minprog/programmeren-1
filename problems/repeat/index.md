# Repeat

Schrijf een programma `repeat.c` dat om een string vraagt, vervolgens een getal, en dan die string meermaals uitprint, namelijk *getal* keer. De herhalingen komen achter elkaar op één regel te staan:

    $ ./repeat
    Wat wil je herhalen? na
    Hoe vaak? 8
    nananananananana

Gebruik de ideeën uit eerdere opdrachten om je programma te ontwerpen.
